# Khutba Bank V3

## Prerequisites:

1. Install [shadcn/ui](https://www.npmjs.com/package/shadcn-ui?activeTab=readme).
2. All the colour and font configurations can be found in `tailwind.config.ts`.
3. Refer to [shadcn/ui docs](https://ui.shadcn.com/docs) if you want to use any components such as button, input box, form, tabs etc.

One of the button code example:

```ts
<Button className='bg-primary text-white font-bold rounded-full'>
	Get Khutba
</Button>
```

4. Here is the [UI Design](https://www.figma.com/file/thFvIqZHAPNUQbbsm6JL19/Khutba-Bank-v3?type=design&t=ngeHCyPBdhOyoUUW-6) of the new website.
